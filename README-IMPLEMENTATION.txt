JOPETNAH INTERNATIONAL LIMITED — NEWSROOM UPDATE

This is an overlay package designed for the existing jopetnah-corporate-site repository. It does not create a separate /news/ section.

Copy these files into the repository root, preserving folders:
- news.html (replace the existing file)
- news-digital-transformation.html (new)
- news-agricultural-value-chains.html (new)
- news-brand-strategy.html (new)
- css/news-articles.css (new)

The updated news.html retains the existing css/style.css and js/script.js, site navigation, footer, canonical URL, social links and branding. Article pages link back to news.html. Featured images currently use remote Unsplash image URLs; for long-term reliability, download approved/licensed images into assets and update the image URLs before publishing.

Before committing: check every article link, validate HTML, preview desktop/mobile layouts, and verify the article quotations and any claims requiring approval.
