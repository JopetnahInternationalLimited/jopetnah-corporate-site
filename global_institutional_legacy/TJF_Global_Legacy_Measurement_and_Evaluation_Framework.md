# TJF Global Legacy Measurement and Evaluation Framework

## Executive Summary

The Jopetnah Foundation (TJF) recognizes that lasting institutional success requires strong systems for measuring performance, learning from experience and demonstrating sustainable impact.

As TJF evolves into a global legacy institution, evaluation must extend beyond short-term activities and focus on long-term transformation, institutional strength and generational impact.

This Global Legacy Measurement and Evaluation Framework establishes the principles, systems and indicators required to measure TJF’s journey toward becoming a globally respected legacy institution.

---

# 1. Purpose

This Framework aims to:

- Establish TJF’s global impact measurement system.
- Evaluate institutional performance.
- Measure long-term transformation.
- Strengthen accountability.
- Support evidence-based decision-making.

---

# 2. Evaluation Vision

To create a world-class measurement system that demonstrates TJF’s contribution to sustainable development, institutional excellence and global transformation.

---

# 3. Evaluation Mission

To collect, analyze and apply evidence that improves programmes, strengthens governance and measures TJF’s long-term legacy impact.

---

# 4. Evaluation Philosophy

TJF believes:

> "What is measured can be improved, and what is improved creates lasting impact."

Effective evaluation requires:

- Evidence.
- Transparency.
- Learning.
- Accountability.
- Continuous improvement.
